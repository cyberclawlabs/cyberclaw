# Agents

在 CyberClaw 中，`Agent` 是角色主体与编排者，不是绕过平台边界的万能执行器。

## Agent 的职责

- 定义“谁来做”
- 持有角色上下文
- 组织执行预算和过程
- 调用 Skill、Connector、Capability

## Agent 不负责什么

- 不直接替代底层执行器
- 不绕过治理链
- 不直接拥有平台级隐藏权限
