# Workflows

Workflow 文档关注的是执行如何被组织，而不是简单的命令清单。

## 在 CyberClaw 中，Workflow 通常关心

- 任务如何进入平台
- Resolver 如何生成执行路径
- 治理与审批何时介入
- Connector 和 Capability 如何承担真实动作
- Artifact / Trace 如何被记录

## 关键执行链

`Task/Case -> Resolver -> Execution -> Governance -> Connector -> Capability -> Artifact/Trace`
