# User Guide

User Guide 面向想要使用或集成 CyberClaw 的开发者。

## 这组文档回答什么

如果你已经知道 CyberClaw 是什么，但还不清楚平台对象如何协作，这一组文档就是入口。

你会在这里看到：

- `Agent` 在平台里扮演什么角色
- `Skill` 和 `Connector` 如何分工
- `Workflow` 在什么层面组织执行
- 为什么治理链是核心，而不是附加能力

## 阅读顺序

1. [Agents](agents.md)
2. [Skills](skills.md)
3. [Connectors](connectors.md)
4. [Workflows](workflows.md)

## 推荐阅读方式

- 想先理解对象边界：从 [Agents](agents.md) 开始
- 想先理解扩展面：从 [Skills](skills.md) 和 [Connectors](connectors.md) 开始
- 想先理解执行链：从 [Workflows](workflows.md) 开始
