# Build a Platform Plugin

如果你的目标是增强平台行为本身，而不是接入外部执行能力，考虑 Platform Plugin。

## Platform Plugin 适合做什么

- 生命周期增强
- 横切能力
- 平台集成扩展

## 不应该做什么

- 不承担业务角色
- 不替代 Connector
- 不绕过治理、审计和追踪
