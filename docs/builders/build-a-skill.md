# Build a Skill

如果你想把方法、知识、提示词、模板和参考资料打包给 Agent 使用，优先从 Skill 开始。

## 适合做成 Skill 的内容

- 方法论
- Prompt 规范
- 参考文档
- 模板与示例
- 对工具表面的说明

## 不适合做成 Skill 的内容

- 直接执行外部动作的运行时逻辑
- 绕过治理链的隐藏执行入口
- 平台级权限管理
