# Approvals and Policies

在 CyberClaw 中，高风险动作不应被默默放行。

## 审批与策略层关心什么

- 风险级别
- 是否需要额外确认
- 动作是否符合执行上下文
- 是否满足平台策略

## 对外表达原则

公开文档应当：

- 说明治理链的设计目标
- 说明当前已实现与路线图的差别
- 不把未闭环能力表述成现成保证
