- Status: Active

CyberClaw 文档分成两层：

1. 产品入口层：面向开源访客、使用者和生态构建者
2. 深度文档层：面向平台开发者和维护者

## 文档标准

公开文档按可直接使用的产品文档标准编写，目标质量对标成熟开发者文档：

- 先说清楚这页解决什么问题
- 先给最短可执行路径，再给深入链接
- 明确前置条件、限制和下一步
- 安装、配置、安全、扩展都用真实入口和真实命令
- 所有对外能力始终区分 `Implemented / In Progress / Roadmap`

详细规则见 [Documentation Quality Standard](development/DOCUMENTATION_QUALITY_STANDARD.md)。
